## Package

<CodeGroup>

```bash npm
npm install @unseen_fi/ui
```

```bash pnpm
pnpm add @unseen_fi/ui
```

```bash yarn
yarn add @unseen_fi/ui
```

</CodeGroup>

**Peer dependencies:** `react` and `react-dom` ≥ 18.
